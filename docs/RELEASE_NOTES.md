# ChatCanvas 1.4.0-rc.12 — Public Preview / 公开测试版

## English

First public-preview packaging under the ChatCanvas name: rich messages, editable canvases, interactive UI previews, math plots and music editing for DeepSeek Harness.

- Independent presentation plugin with its own settings and package identity.
- Fixed image-attachment overlap, canvas pan feedback, live erasure, alignment, context menus and bounded toolbars.
- Plain-text boxes preserve text/line breaks; writing boxes preserve rich formatting.
- Unified layer ordering; new UI pages default to transparent backgrounds.
- English and Simplified Chinese documentation. Current interface language: Simplified Chinese.

Download `local-dsh-chatcanvas-1.4.0-rc.12.tgz` to install. The source archive is for development. See the README installation instructions and verify the asset against SHA256SUMS.txt.

This is a preview. Verified host integration targets: 0.2.0-rc.2 and 0.2.1-rc.2. Other host versions and operating systems are unverified. Back up your profile before upgrading. Real-window visual acceptance and long-session behavior remain areas for testing.

## 简体中文

以“对话画布 · ChatCanvas”名称整理的首个公开测试包，提供富文本、可编辑画布、交互 UI、数学图像与音乐编辑。

- 独立的界面增强插件，拥有自己的设置和包名。
- 修复附件图片重叠、画布平移反馈、实时擦除、对齐吸附、右键菜单和侧栏溢出。
- 纯文本框仅保留文字及换行；写作框保留富文本。
- 层级统一按数值由小到大绘制，新 UI 页面默认透明。
- 提供中英文说明；当前界面为简体中文。

安装下载 `local-dsh-chatcanvas-1.4.0-rc.12.tgz`，源码包供开发使用。请按 README 操作，并对照 SHA256SUMS.txt 校验文件。

当前是测试版，已验证的宿主集成目标为 0.2.0-rc.2、0.2.1-rc.2；其他版本和操作系统尚未验证。升级前备份 profile。正式窗口视觉体验及长时间使用仍需要更多测试。
