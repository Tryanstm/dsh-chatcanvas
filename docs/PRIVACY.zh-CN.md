# 隐私与模型用量

ChatCanvas 是界面与结构化内容插件，不接管工具执行审核，也不改变宿主权限预设；没有插件自有统计上报接口。

编辑、预览和音频转录使用本地代码及随包资源。发送消息通过宿主原生消息／附件链路。AI 文字推荐、翻译及其质量检查会调用 Harness 当前配置的模型，可能增加费用；选中文字及相关编辑指令会进入这些请求。

新会话的首条用户消息包含富文本时，自动生成标题还可能额外调用当前模型／服务商。请求会包含消息及视觉内容的简短描述（最多 4,000 个字符），不直接发送结构化传输封装或运行代码；这也可能产生模型用量。

UI 预览程序不能任意读取宿主文件或访问网络。已发布作品、编辑草稿及设置保存在本地。请勿将 API 密钥、私人聊天或个人文件放入公开截图和问题报告。

使用默认宿主数据目录时，插件设置保存在 `storages/chatcanvas-preferences.json`。已发布内容沿用兼容的 `storages/dsh-enhanced-renderer/` 目录，编辑草稿使用宿主浏览器存储。旧标识用于兼容历史内容，不代表又安装了另一个插件。迁移时应与宿主会话及附件数据一同备份。
